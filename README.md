# Retail Sales Data Analysis

## Project Overview
This project analyzes retail store sales data using Python. The goal is to understand sales performance, customer transactions, product demand, payment methods, and business trends.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Excel
- ReportLab

## Dataset Information
- Original records: 12,575
- Cleaned records: 11,362
- Total columns: 11
- Missing values after cleaning: 0
- Duplicate rows: 0

## Data Cleaning
The following cleaning activities were performed:
- Converted transaction dates into datetime format.
- Handled missing values in Item and Discount Applied.
- Removed rows with missing numerical values.
- Checked for duplicate records.
- Saved the cleaned dataset.

## Analysis Performed
- Total revenue and average transaction value
- Sales by category
- Sales by payment method
- Sales by location
- Top-selling items
- Monthly and yearly revenue trends
- Customer transaction analysis
- Daily and weekly sales analysis

## Key Business Insights
- Total Revenue: 1,472,998.50
- Total Transactions: 11,362
- Total Customers: 25
- Highest Revenue Category: Butchers
- Best Payment Method: Cash
- Best Performing Location: Online
- Best Selling Item: Item_2_BEV
- Highest Revenue Month: January
- Highest Revenue Year: 2024
